# Excel Business Cleaner

A Python-based application that cleans Excel and CSV files using Streamlit and Pandas.

## Features

- Upload Excel and CSV files.
- Automatically standardise column names.
- Remove duplicate rows.
- Remove unnecessary spaces.
- Generate missing-value reports.
- Process multiple Excel sheets.
- Download cleaned Excel files and quality reports.

## Technologies Used

- Python
- Pandas
- Streamlit
- OpenPyXL

## Installation

Clone the repository:

    git clone https://github.com/jason7716/excel-business-cleaner.git

Install dependencies:

    pip install -r requirements.txt

## Run the Application

    streamlit run app.py
